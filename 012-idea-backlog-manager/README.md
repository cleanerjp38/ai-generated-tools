# 012 Idea Backlog Manager

AI生成ツール候補のMarkdownネタ帳を読み込み、  
検索・絞り込み・進捗管理・ランダム選択を行うためのローカルGUIツール。

## Features

- Markdownからツール候補を自動読み込み
- キーワード検索
- カテゴリ絞り込み
- 難易度絞り込み
- 状態絞り込み
- 詳細表示
- 進捗状態の保存
- 条件に合う候補からランダム選択

## Status

候補ごとに以下の状態を設定できる。

- 未着手
- 次に作る
- 作業中
- 完成
- 保留

進捗は `progress.json` に保存される。

## Files

- `main.py`
  - GUI
  - Markdown解析
  - 検索
  - 絞り込み
  - 状態管理
  - ランダム選択
- `ideas.md`
  - AI生成ツール候補のネタ帳
- `progress.json`
  - 各候補の進捗状態を保存
- `README.md`
  - このツールの説明

## Run

Python 3で実行する。

```powershell
python main.py
```

Tkinterを使用しているため、追加ライブラリは不要。

## How it works

```text
ideas.md
   ↓
Markdown parser
   ↓
Python data
   ↓
Tkinter GUI
   ↓
Search / Filter / Random Select
   ↓
progress.json
```

`ideas.md` の内容そのものは進捗管理のために書き換えず、  
状態だけを `progress.json` に分離して保存する。

これにより、ネタ帳へ新しい候補を追加しても、既存の進捗情報を維持できる。

## Main structure

### Markdown parser

`ideas.md` 内の見出しや項目を読み取り、ツール候補として解析する。

例:

```text
## 1-A. Character Parameter Generator

身長、髪型、髪色、体型、服装などをランダム生成する。

- 完成条件：ボタン1つでキャラクター設定が表示される
- 難易度：★
- 技術：HTML / JavaScript
```

この情報をPython内部では、ID・名前・カテゴリ・説明・難易度などのデータとして扱う。

### GUI

Tkinterを使って候補一覧と詳細画面を表示する。

一覧から候補を選択すると、右側に以下の情報を表示する。

- ID
- ツール名
- カテゴリ
- 説明
- 完成条件
- 難易度
- 技術
- 新技術

詳細欄はテキストとして選択できるため、タイトルや説明をそのままコピーできる。

### Filtering

以下の条件で候補を絞り込める。

- キーワード
- カテゴリ
- 難易度
- 状態

複数条件を組み合わせることもできる。

### Random selection

現在の絞り込み結果から1件をランダムに選択する。

例えば、

```text
カテゴリ：人口シミュレーション
難易度：★
状態：未着手
```

という条件にしてからランダム選択すると、  
その条件に一致する候補だけから1件が選ばれる。

### Progress management

進捗状態は `progress.json` に保存する。

例:

```json
{
  "1-A": "完成",
  "3-E": "次に作る",
  "6-I": "作業中"
}
```

アプリを終了して再起動しても状態は保持される。

## What I learned

- Markdownを簡単なデータソースとして利用できる
- 正規表現を使って見出しや属性を解析できる
- GUI表示用データと進捗データを分離できる
- JSONを使ってアプリの状態を保存できる
- Tkinterで一覧・詳細表示・フィルターを組み合わせられる
- 絞り込み結果をそのまま別機能へ利用できる
- 元データとユーザー操作による状態データを分離すると管理しやすい

## Parent idea

AI生成ツール候補ネタ帳の管理。

大量の候補から、その日の体力・興味・難易度に応じて  
次に作るツールを選びやすくするために作成した。

AI生成ツール30個プロジェクトでは、  
「何を作るか悩む時間」を減らし、実際の開発へすぐ移れるようにすることを目的としている。
