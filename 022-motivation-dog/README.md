# 022 Motivation Dog 🐶

やる気が出ないときに、犬がランダムな言葉をかけてくれるシンプルなWebアプリです。

AI生成ツール30個プロジェクトの **22個目** として作成しました。

## 概要

犬をクリックすると、励ましの言葉や名言風の言葉、休息を勧める言葉などがランダムに表示されます。

必ずしも「頑張れ」と励ますのではなく、ときには「今日は休もう」と声をかけてくれるのが特徴です。

以前作成した `008-comfort-dog` と `013-mood-dog` の経験を活かし、できるだけ操作を単純にしました。

**犬をクリックするだけで使えます。**

## 機能

### 1. ランダムメッセージ

犬をクリックすると、60種類のメッセージからランダムに1つ表示されます。

メッセージは以下の4ジャンルに分かれています。

| ジャンル | 内容 | メッセージ数 |
|---|---|---:|
| 励まし | 行動や挑戦を後押しする | 15 |
| 名言風 | 物事の見方を変える | 15 |
| 休息 | 休むことを勧める | 15 |
| ユーモア | 犬らしい冗談や脱力する言葉 | 15 |
| **合計** | | **60** |

ジャンルを選択する必要はありません。

すべてのメッセージからランダムに選ばれます。

### 2. 連続重複防止

同じメッセージが2回連続で表示されないようにしています。

直前に表示したメッセージの番号を記憶し、次の抽選で同じ番号が選ばれた場合は再抽選します。

### 3. シンプルな操作

気分選択や設定画面はありません。

犬をクリックするだけで新しいメッセージが表示されます。

## 使い方

1. `index.html` をブラウザで開く
2. 画面中央の犬をクリックする
3. ランダムに表示されるメッセージを読む
4. もう一度クリックすると別のメッセージが表示される

サーバーの起動やライブラリのインストールは必要ありません。

## プログラムの仕組み

### 1. メッセージをジャンル別に管理

メッセージは4つの配列に分けて保存しています。

```javascript
const encouragement = [
  "今日は1ミリ進めば勝ちだワン。",
  "まず5分だけやるワン！"
];

const wisdom = [
  "遠回りも、歩いた距離には違いないワン。"
];

const rest = [
  "今日は休むワン。明日も世界は残っているワン。"
];

const humor = [
  "やる気を探していたら、おやつを見つけたワン。"
];
```

### 2. スプレッド構文で配列を統合

JavaScriptのスプレッド構文 `...` を使用して、4つの配列を1つにまとめています。

```javascript
const messages = [
  ...encouragement,
  ...wisdom,
  ...rest,
  ...humor
];
```

ジャンル別にメッセージを管理しながら、ランダム抽選ではすべてのメッセージをまとめて扱えます。

### 3. ランダムな番号を生成

```javascript
randomIndex = Math.floor(Math.random() * messages.length);
```

`Math.random()` で乱数を生成し、`Math.floor()` で整数に変換します。

生成された番号を使って、配列からメッセージを取得します。

### 4. 連続重複を防止

```javascript
let previousIndex = -1;

function showMessage() {
  let randomIndex;

  do {
    randomIndex = Math.floor(Math.random() * messages.length);
  } while (
    messages.length > 1 &&
    randomIndex === previousIndex
  );

  previousIndex = randomIndex;

  document.getElementById("message").textContent =
    messages[randomIndex];
}
```

`previousIndex` に直前のメッセージ番号を保存しています。

新しい番号が直前と同じ場合は、`do...while` によって再抽選します。

メッセージが1種類しかない場合でも、無限ループしないようにしています。

### 5. クリックイベント

```javascript
document.getElementById("dogButton")
  .addEventListener("click", showMessage);
```

犬のボタンがクリックされたときに、`showMessage()` を実行します。

## 今回の学び

### スプレッド構文

`...` を使用すると、複数の配列の要素を展開してまとめられることを確認しました。

### do...while

処理を最低1回実行し、条件を満たす間は繰り返す構文です。

今回は、直前と異なるメッセージが選ばれるまで抽選するために使用しました。

### ユーザー体験の設計

以前作成した `013-mood-dog` は、気分を選択してからメッセージを表示する仕組みでした。

しかし、実際に使ってみると、操作が単純な `008-comfort-dog` の方が癒されると感じました。

そこで今回は、気分選択をなくして犬をクリックするだけの操作にしました。

**機能を増やすことが、必ずしも使いやすさの向上につながるわけではない**と学びました。
