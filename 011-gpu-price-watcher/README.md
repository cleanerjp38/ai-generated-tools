# 011 GPU Price Watcher

価格.comからGeForce RTX 5070の最安価格を取得し、前回取得した価格と比較するPythonツールです。

AI生成ツール30個プロジェクトの11個目として作成しました。

## 機能

- 価格.comからGeForce RTX 5070の価格情報を取得
- 最安価格を抽出
- 前回取得した価格をJSONファイルに保存
- 前回価格と今回価格を比較
- 値下がり・値上がり・価格変動なしを表示

実行例：

```text
今回の最安値: 138,000円
前回の最安値: 143,000円
↓ 5,000円 値下がり！
今回の価格を保存しました
```

価格が変わらなかった場合：

```text
今回の最安値: 138,000円
前回の最安値: 138,000円
→ 価格変動なし
今回の価格を保存しました
```

## 処理の流れ

```text
価格.com
   ↓
requestsでHTMLを取得
   ↓
BeautifulSoupでテキストを抽出
   ↓
正規表現で価格を取得
   ↓
現在の最安価格を決定
   ↓
prices.jsonから前回価格を読み込む
   ↓
前回価格と現在価格を比較
   ↓
値下がり / 値上がり / 変化なしを表示
   ↓
現在価格をprices.jsonへ保存
```

```powershell

```

初回実行時は前回価格が存在しないため、現在価格を `prices.json` に保存します。

2回目以降は保存されている前回価格と現在価格を比較します。

## 今回学んだこと

### Webページから価格を取得する

`requests` を使ってWebページのHTMLを取得しました。

価格.comでは文字コードとしてShift_JISが使われていたため、取得したHTMLの文字コードを指定する必要がありました。

### BeautifulSoupによるHTML解析

BeautifulSoupを使ってHTMLからテキスト部分を取り出しました。

### 正規表現による価格抽出

取得したテキストから、

```text
¥138,000
```

のような価格情報を正規表現で抽出しました。

### データの永続化

これまで作ったツールの多くは、プログラムを終了すると実行時の情報も失われていました。

今回は `prices.json` に価格を保存することで、

```text
1回目の実行
    ↓
価格を保存
    ↓
プログラム終了
    ↓
2回目の実行
    ↓
前回価格を読み込む
```

という、複数回の実行をまたいだデータ保存を経験しました。

### 前回データとの比較

現在価格と保存されている価格との差額を計算し、

- 値下がり
- 値上がり
- 価格変動なし

を判定する処理を実装しました。

## 注意点

このツールは価格.comのHTML構造に依存しています。

サイト側のHTML構造や表示方法が変更された場合、価格を取得できなくなる可能性があります。

また、短時間に大量のアクセスを行う用途は想定していません。
