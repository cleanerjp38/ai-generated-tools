# 013 Mood Dog 🐶

そのときの気分に合わせて、犬がランダムなメッセージを表示してくれるシンプルなWebツールです。

AI生成ツール30個プロジェクトの **13個目** として作成しました。

## 機能

4種類の気分から現在の状態を選択できます。

- 😫 疲れた
- 😟 不安
- 😠 イライラ
- 💻 勉強・開発疲れ

気分を選択すると、そのカテゴリに登録されているメッセージからランダムで1つ表示されます。

「🐾 もう一言」ボタンを押すと、同じカテゴリから再びランダムにメッセージを表示します。

## 使い方

`index.html` をブラウザで開くだけで使用できます。

サーバーの起動やライブラリのインストールは必要ありません。

## 仕組み

メッセージはJavaScriptのオブジェクトに、気分ごとに分けて保存しています。

```javascript
const messages = {
  tired: [
    "メッセージ1",
    "メッセージ2"
  ],

  anxious: [
    "メッセージ1",
    "メッセージ2"
  ]
};
```

ユーザーが気分を選ぶと、そのカテゴリの配列を取得します。

```javascript
const moodMessages = messages[currentMood];
```

その後、配列の中からランダムな位置を選択します。

```javascript
const randomIndex =
  Math.floor(Math.random() * moodMessages.length);
```

選ばれたメッセージを画面に表示します。

## 今回のポイント

### データと処理を分ける

メッセージそのものは `messages` に保存し、ランダム選択の処理は `showMessage()` が担当しています。

そのため、メッセージを増やしてもランダム選択の処理を書き換える必要がありません。

今回、メッセージ数を増やしても `showMessage()` はそのまま利用できました。

小さなツールですが、

**「データを増やしても処理部分を変更しなくてよい構造」**

を確認できました。
