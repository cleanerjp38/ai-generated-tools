# 007 - 今日のニュース・ランダマイザー

今日公開されたニュース記事の中から、ランダムに10本を選んで表示するCLIツールです。

AI生成ツール30個プロジェクトの7作目です。

## 目的

Webスクレイピングの基本的な流れを体験するために作成しました。

ニュースサイトからHTMLを取得し、記事タイトルとURLを抽出して、その中から今日の記事だけをランダムに表示します。

## 使用技術

- Python
- requests
- BeautifulSoup4
- datetime
- random

## 処理の流れ

```text
ニュースサイトのHTMLを取得
        ↓
BeautifulSoupでHTMLを解析
        ↓
<a>タグから記事リンクを抽出
        ↓
今日の記事だけ候補化
        ↓
ランダムに最大10本選択
        ↓
タイトルとURLを表示
```

## ファイル構成

```text

├── main.py

└── README.md
```

### main.py

ニュースページの取得、HTML解析、記事抽出、日付判定、ランダム選択、結果表示を行います。

### requirements.txt

必要な外部ライブラリを記載しています。

## インストール

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

```text

https://example.com/article/...
```

## スクレイピングの仕組み

`requests` を使ってWebページのHTMLを取得します。

取得したHTMLを `BeautifulSoup` で解析し、ページ内の `<a>` タグを調べます。

今回使用したページでは、ニュース記事へのリンクが `/v/article/` から始まっていたため、この特徴を利用して記事リンクだけを抽出しています。

さらに、記事タイトルに含まれる日付と現在の日付を比較し、今日の記事だけを候補として保存します。

最後に `random.sample()` を使い、候補から重複なしで最大10本を選択します。

## 学んだこと

今回の制作では、Webスクレイピングの基本的な流れを体験しました。

特に、

- HTTPリクエストでHTMLを取得する
- HTMLの構造を実際に観察する
- 必要な要素を見分ける規則を探す
- BeautifulSoupでHTMLから情報を抽出する
- 相対URLを完全なURLに変換する
- 日付でデータを絞り込む
- `random.sample()` で重複なしのランダム抽出を行う

という流れを確認できました。

スクレイピングでは、最初から抽出条件が分かっているわけではなく、実際のHTMLや取得結果を確認して「どのような規則で目的のデータを見分けられるか」を探すことが重要だと分かりました。

## 注意

このツールは対象WebサイトのHTML構造に依存しています。

サイト側のページ構造やURL形式などが変更された場合、記事を取得できなくなる可能性があります。

また、スクレイピングを行う場合は、対象サイトの利用規約やアクセス頻度などに配慮する必要があります。
