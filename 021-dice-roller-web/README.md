
# 021 Dice Roller Web

HTML・CSS・JavaScriptで作成した、ブラウザ上で動作するダイスローラー。

ChatGPTとのごっこ遊びやTRPGなどで、手軽にダイスを振ることを目的として開発した。

## 機能

- D4、D6、D8、D10、D12、D20、D100に対応
- ダイスの個数を1〜10個から選択
- 補正値を-10〜+10の範囲で設定
- 各ダイスの出目と合計値を表示
- 直近10回のロール履歴を表示
- 結果をクリップボードにコピー
- 履歴の消去

## 使い方

1. `index.html` をブラウザで開く
2. ダイスの種類、個数、補正値を選択
3. 「ダイスを振る！」をクリック
4. 必要に応じて「結果をコピー」をクリック

### 使用例

3個の12面ダイスを振る場合：

```text
3D12 → [8, 6, 6] 合計: 20
```

補正値を設定した場合は、合計値に加算または減算される。

## 使用技術

- HTML5：画面の構造
- CSS3：画面デザイン
- JavaScript：ダイス処理、履歴管理、コピー機能
- Web Crypto API：乱数生成

外部ライブラリやサーバーは使用していない。

## プログラムの動作

1. ユーザーがダイスの種類・個数・補正値を選択する
2. JavaScriptが設定値を取得する
3. `crypto.getRandomValues()` を使用して乱数を生成する
4. 各ダイスの出目を配列に格納する
5. 出目の合計に補正値を加える
6. 結果を画面に表示する
7. 結果を履歴配列に追加する

乱数を指定範囲に変換する際には、剰余による偏りを避けるために棄却法を使用している。

## 004 Dice Rollerとの違い

以前作成した `004-dice-roller` はPython製のCLIツールだった。

今回のWeb版では、ブラウザ上で操作できるGUIを採用した。

主な改善点：

- コマンドラインを使わずに起動できる
- ダイスの種類や個数を画面上で選択できる
- 複数の出目を視覚的に確認できる
- ロール履歴を確認できる
- ChatGPTに貼り付けるためのコピー機能を追加した
