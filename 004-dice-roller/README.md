# 004 Dice Roller

ダイス記法を入力すると、ランダムにダイスを振って結果を表示するシンプルなCLIツールです。

## 機能

以下のようなダイス記法に対応しています。

```text
2d6
1d20
4d5+3
```

例：

```text
ダイスを入力してください（例: 2d6, 2d6+3）: 4d5+3
出目: [1, 1, 1, 4]
補正: 3
合計: 10
```

`4d5+3` は、

- 5面ダイスを4個振る
- 出目を合計する
- 最後に3を加える

という意味です。

## 使用技術

- Python 3
- random（標準ライブラリ）

外部ライブラリは使用していません。

## 実行方法

```bash
python main.py
```

実行後、ダイス記法を入力します。

```text
2d6+3
```

### main.py

ダイス記法の解析、乱数生成、合計値の計算、結果表示を担当します。

## 処理の流れ

```text
"2d6+3" を入力
    ↓
"2d6" と "+3" に分ける
    ↓
ダイスの個数「2」と面数「6」を取得
    ↓
1〜6の乱数を2回生成
    ↓
出目を合計
    ↓
補正値3を加える
    ↓
結果を表示
```

## なぜPythonを使ったのか

本格的なゲーム開発では、C++やC#などもよく使われます。

今回はゲーム本体ではなく、ダイス処理という小さな仕組みを単独で試すツールです。

Pythonは標準ライブラリだけで簡単に乱数処理や文字列処理を書けるため、短時間で仕組みを実装して動作を確認する用途に向いています。

将来ゲームを制作するときに別の言語を使う場合でも、「ダイス記法を解析して乱数を生成し、補正値を加える」という基本的な設計は応用できます。
