# 010 日本の人口シミュレーター

出生率と移民純流入数を変更して、日本の人口が将来どのように変化するかを簡易的にシミュレーションするWebツールです。

ブラウザだけで動作し、入力した条件に応じて将来人口と人口推移のグラフを表示します。

## 機能

- 現在人口を設定
- 合計特殊出生率を設定
- 年間の移民純流入数を設定
- シミュレーション年数を設定
- 指定年数後の人口を計算
- 現在人口からの増減率を表示
- Canvasを使って人口推移をグラフ表示

## 使用技術

- HTML
- CSS
- JavaScript
- Canvas API

外部ライブラリは使用していません。

## 使い方

`index.html` をブラウザで開きます。

以下の値を入力します。

1. 現在の人口
2. 合計特殊出生率
3. 年間の移民純流入数
4. シミュレーション年数

「シミュレーションする」ボタンを押すと、指定年数後の人口と人口推移グラフが表示されます。

## 計算モデル

このツールでは、人口変化を大幅に単純化しています。

自然増減率を次の式で計算しています。

```javascript
const naturalChangeRate = (fertility - 2.1) * 0.01;
```

その後、1年ごとに次の計算を行います。

```javascript
population =
    population * (1 + naturalChangeRate)
    + immigration;
```

つまり、

```text
前年の人口
↓
出生率から求めた簡易的な自然増減
↓
年間の移民純流入を追加
↓
翌年の人口
```

という流れを指定された年数だけ繰り返しています。

## 注意

このツールは、人口変化の仕組みを試すための教育・実験用シミュレーターです。

実際の日本の将来人口を予測するものではありません。

現実の人口推計では、出生率だけでなく、

- 年齢別人口
- 男女別人口
- 年齢別出生率
- 死亡率
- 平均寿命
- 出入国者の年齢構成
- 移民した人々やその子どもの出生
- 世代ごとの人口構成

など、多数の要素を考慮する必要があります。

このツールでは、それらを扱わず単純な計算モデルを使用しています。

そのため、特に数十年以上の長期シミュレーションでは、現実の人口推計とは大きく異なる結果になる可能性があります。
