

\# 020 Choice Adventure



選択肢を選んで物語を進める、ブラウザ型の短編異世界RPG。



AI生成ツール30個プロジェクトの第20作目。



\## 機能



\- 選択肢によるストーリー分岐

\- HPの増減と回復

\- HPが0になるとゲームオーバー

\- 3種類のエンディング

\- ゲームのリスタート

\- オフライン動作



\## 使用技術



\- HTML

\- CSS

\- JavaScript



外部ライブラリやAPIは使用していない。



\## 実行方法



`index.html` をブラウザで開く。



インストールやサーバー起動は不要。



\## ファイル構成



\- `index.html`：画面・デザイン・ゲーム処理

\- `README.md`：ツールの説明



\## プログラムの構造



\### scenes



物語の場面、選択肢、HP変化、遷移先を管理する。



\### choose()



プレイヤーの選択を処理する。



HPの増減、ゲームオーバー判定、次の場面への移動を担当する。



\### render()



現在のHP、物語、選択肢を画面に表示する。



\### restart



HPと進行状況を初期化し、ゲームを最初から開始する。
