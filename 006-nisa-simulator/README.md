# 006 NISA積立シミュレーター

毎月の積立額・想定年利・積立年数を入力すると、積立後の資産額を計算するシンプルなWebアプリです。

## 機能

以下の3項目を入力できます。

- 毎月の積立額
- 想定年利
- 積立年数

「計算する」ボタンを押すと、以下を表示します。

- 元本
- 運用益
- 最終金額

## 使用技術

- HTML
- CSS
- JavaScript

外部ライブラリやAPIは使用していません。

## 使い方

`index.html` をブラウザで開きます。

値を入力して「計算する」ボタンを押すと、計算結果が表示されます。

例：

```text
毎月の積立額：30,000円
想定年利：5%
積立年数：20年

元本：7,200,000円
運用益：5,131,010円
最終金額：12,331,010円
```

## 計算方法

年利を12で割って月利に変換し、毎月末に一定額を積み立てるものとして複利計算しています。

概念的には、定額積立の将来価値を求めています。

年利が0%の場合は複利計算で0除算が発生するため、元本をそのまま最終金額として扱います。

※ 実際の投資では毎年一定の利回りになるとは限りません。このツールは将来の運用成果を保証するものではなく、単純化したシミュレーションです。

## プログラムの流れ

```text
ユーザーが値を入力
        ↓
「計算する」をクリック
        ↓
JavaScriptが入力値を取得
        ↓
元本と複利運用後の金額を計算
        ↓
運用益を計算
        ↓
HTMLの計算結果を書き換える
```

## 開発中に起きた問題

最初はJavaScriptの`<script>`を`<body>`より前に配置していたため、JavaScript実行時点では「計算する」ボタンがまだ読み込まれていませんでした。

そのため、ボタンを押しても計算が実行されませんでした。

`<script>`を`</body>`の直前へ移動し、HTML要素が作られた後にJavaScriptを実行することで解決しました。
