# 008 Comfort Dog 🐶

落ち込んだときや疲れたときに、犬がランダムなメッセージで慰めたり全肯定してくれるシンプルなWebツールです。

## 機能

- 「なぐさめてもらう」ボタンを押すとメッセージをランダム表示
- 慰め系・全肯定系のメッセージを収録
- ブラウザだけで動作
- 外部ライブラリやAPIは不使用

## 使用技術

- HTML
- CSS
- JavaScript

## 使い方

1. `index.html` をブラウザで開く
2. 「なぐさめてもらう」ボタンを押す
3. 犬に慰めてもらう 🐶

## 仕組み

メッセージをJavaScriptの配列に保存しています。

ボタンがクリックされると `Math.random()` でランダムなメッセージを1つ選び、画面のテキストを書き換えます。

```text
ボタンをクリック
      ↓
ランダムな番号を生成
      ↓
配列からメッセージを選択
      ↓
画面に表示
```

## 今後追加できそうな機能

- 犬の画像をランダム表示
- 犬をクリックすると反応する機能
- 犬モード・女の子モードの切り替え
- メッセージの追加
- 時間帯によってメッセージを変更
