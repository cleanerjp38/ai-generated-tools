# 018 ChatGPT Conversation Exporter

現在開いているChatGPTの会話を、JSON形式で保存するChrome拡張機能。

AI生成ツール30個プロジェクトの18個目。

## 概要

ChatGPTの会話ページから、ユーザーとChatGPTの発言を抽出してJSONファイルに保存する。

保存形式は、014〜017の会話処理ツールと共通の `role` / `text` 形式。

**注意：会話全体の完全なエクスポートを保証するツールではありません。**

## 主な機能

- Chrome拡張機能のボタンから会話を保存
- ユーザーとChatGPTの発言を区別
- 発言を時系列順にJSON化
- 発言件数を表示
- ローカルで処理し、外部サーバーには送信しない

## 使用技術

- JavaScript
- HTML
- Chrome Extensions Manifest V3
- Chrome Scripting API

外部ライブラリは使用しない。

## インストール方法

1. Chromeで `chrome://extensions` を開く
2. デベロッパーモードを有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選択
4. `018-chatgpt-conversation-exporter` フォルダを指定する

## 使い方

1. ChatGPTの会話ページを開く
2. 拡張機能のアイコンをクリック
3. 「会話を保存」を押す
4. JSONファイルがダウンロードされる

## 出力形式

```json
[
  {
    "role": "user",
    "text": "こんにちは"
  },
  {
    "role": "assistant",
    "text": "こんにちは！"
  }
]
```

ファイル名の例：

```text
chatgpt-conversation-2026-10-14T06-00-00-000Z.json
```

## 動作の仕組み

1. Chromeの現在のタブを取得する
2. ChatGPTのページであることを確認する
3. 表示中の `main` 要素を探す
4. `data-turn-key` を持つ会話要素を取得する
5. 「あなたの発言:」「ChatGPT の発言:」を基準に文章を分割する
6. `role` と `text` の配列に変換する
7. JSONファイルを生成してダウンロードする

## 動作確認

2026年10月14日、ChromeのChatGPT画面で検証。

### 短い会話

ユーザー3件、ChatGPT3件のテスト会話を使用。

結果：

- 合計6件を取得
- 発言者の区別に成功
- 発言順序を維持
- JSON保存に成功
- 末尾に混入していた「PDF に変換」を除去

### 長い会話

長い開発チャットでもJSON保存に成功したが、会話全体ではなく一部の発言のみ取得された。

共有リンクから開いた会話でも、一部の発言のみ取得された。

## 既知の制限

- 長い会話では、すべての発言を取得できない場合がある
- 画面に読み込まれていない発言は取得できない
- ChatGPTのHTML構造が変わると動作しなくなる可能性がある
- 日本語UIの発言ラベルを前提としている
- 発言本文に区切り用ラベルと同じ文字列が含まれると誤分割する可能性がある
- コードブロックの言語名や操作UIなど、本文以外の文字列が混入する場合がある
- 「PDF に変換」という末尾文字列の除去は暫定的な処理である
- 画像、添付ファイル、特殊な表示要素の完全な保存には対応していない

## セキュリティ・プライバシー

- 外部サーバーへの会話送信機能はない
- APIキーや認証情報を使用しない
- Chromeの権限は `activeTab` と `scripting` に限定
- 会話データはユーザーのPCにJSONファイルとして保存される
- 実際の会話ログや個人情報をGitHubへ公開しない

## 今後の改良案

- 長い会話の全履歴取得
- HTML構造に依存しにくい発言者識別
- 操作UIの文字列混入を防ぐ
- Markdown形式での保存
- 会話タイトルをファイル名に使用
- 公式エクスポートデータとの連携

## 開発で学んだこと

### 1. HTML構造は想定と違う場合がある

当初は `data-message-author-role` を使う設計だったが、実際の画面では見つからなかった。

開発者ツールを使ってHTML構造を調査し、別の抽出方法に変更した。

### 2. 非表示の会話が残っている場合がある

ChatGPTの画面には、以前のチャットのHTMLが非表示で残っている場合があった。

表示中の `main` 要素だけを対象にすることで、別のチャットの混入を回避した。
